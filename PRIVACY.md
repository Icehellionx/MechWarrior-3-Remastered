# Privacy

The installer and launcher contain no telemetry, analytics, advertising, accounts, update checks, or project-operated network services. They do not upload ISO contents, file hashes, installation paths, or gameplay information.

The selected MechWarrior 3 ISO path and Pirate's Moon media type are stored locally in `install.cfg` under the chosen installation directory. Pirate's Moon ISO, RIP, and ISO-version ZIP/BIN/CUE content is read only during setup and is not needed by the launcher afterward. Temporary expansion and conversion files are removed with setup staging. Compatibility components can create local diagnostic logs in the game directories. Those files are not transmitted by this project.

Windows, Microsoft Defender SmartScreen, antivirus products, GitHub, and the original game may have behavior or privacy policies outside this project's control.
