No game code or binary from the Pirate's Moon RIP, ISO-version archive, or crack is embedded in this installer. Setup can read the supported RIP ZIP/folder or ISO/BIN/CUE media selected by the user, verify its executable, and install only the required game payload. The true disc executable receives a deterministic 12-byte runtime-path normalization plus two disc-check branch changes; the partly normalized RIP retail executable needs only the two branch changes. Both transformations produce the same supported no-disc executable hash. Pirate's Moon media is not required after installation.
