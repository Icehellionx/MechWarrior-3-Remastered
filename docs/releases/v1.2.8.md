# v1.2.8

MechWarrior 3 Remastered v1.2.8 adds launcher Settings, Help/Credits and sanitized Diagnostics, corrects Pirate's Moon edge repair, and improves installation on clean Windows systems and Wine.

- New per-game graphics Settings preserve profile ownership and reject conflicts with running games, overrides and recovery state. Qualified choices are 4x MSAA and off; filtering remains fixed.
- Typed Windows Shell Links replace dynamic WScript finalization, fixing the reported Wine shortcut failure.
- Read-only PM media installation now replaces only its owned staged executable without changing source media.
- Source-built static-runtime ZipperFixup removes the clean-system VC++ runtime dependency; patch outputs and r18 graphics wrapper are unchanged.
- PM now enables the existing four-pixel presentation edge repair, verified against the orange top/left seam on physical Windows hardware.
- Runtime loader failures are reported without futile graphics retries; modeless Cancel/Close behavior is corrected.
- Installer prompts and README explicitly require game copies the user owns. No game ISO or RIP is included.
