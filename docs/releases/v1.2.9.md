# v1.2.9

MechWarrior 3 Remastered v1.2.9 folds the mounted-CD workaround from issue #1 into Wine setup and makes the seven-effect sound adjustment automatic.

- Setup detects Wine, uses the CD-folder picker as its primary media action and automatically selects a unique readable mapped MW3 disc with the retail volume label and installer cabinets. Ambiguous or missing discs remain a folder selection.
- Under Wine, mount your own CD or ISO/BIN/CUE image with Linux tools and keep its CD-ROM mapping available while playing. Setup and launcher avoid unsupported Windows ISO-mount commands and preserve external mounts.
- Mounted Pirate's Moon cabinet folders use the same borrowed-media session; existing RIP folder installation remains supported.
- Setup always lowers the seven unusually loud base-game effects. The checkbox is removed. Exact-hash originals remain in `MechWarrior 3/OriginalSoundArchives`, with `Use-SoundLevelCandidate.ps1` for restoration. Pirate's Moon effects and CD music are unchanged.
- The r18 graphics wrapper, game executable transformations and CD-audio backend are unchanged.
