MechWarrior 3 Remastered

Open MechWarrior 3 Remastered from the desktop or Start menu. Its launcher provides one place to start either installed game or open either original manual. Keep the MechWarrior 3 ISO at the path selected during setup; the launcher mounts it before starting the base game. Pirate's Moon media is not needed again after setup, whether installation used an ISO, RIP ZIP/folder, or ISO-version BIN/CUE ZIP.

The tested 1024x768 gameplay mode is scaled to your desktop resolution. The game also requires its legacy 640x480 mode for startup videos. Do not change resolution from the legacy in-game menu because doing so can crash the game. Control mappings are saved under each game's keys folder.

The launcher's UNINSTALL button removes the remaster while preserving saved pilots and campaign progress under each game's pilots folder. A later reinstall to the same location safely carries those saves into the new installation. Control mappings and other settings are not preserved.

The original manuals are installed in the Manuals folder and linked from both the launcher and the MechWarrior 3 Remastered Start-menu group.
