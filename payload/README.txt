MechWarrior 3 Remastered

Open MechWarrior 3 Remastered from the desktop or Start menu. Its launcher provides one place to start either installed game or open either original manual. Keep ISO files at the paths selected during setup; the launcher mounts the appropriate original disc before starting each game. Pirate's Moon installations made from the RIP ZIP/folder do not need that source again after setup.

The original manuals are installed in the Manuals folder and linked from both the launcher and the MechWarrior 3 Remastered Start-menu group.
