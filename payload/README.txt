MechWarrior 3 Remastered

Launch from the desktop or Start menu shortcut. Keep ISO files at the paths selected during setup; the launcher mounts the appropriate original disc before starting each game. Pirate's Moon installations made from the RIP ZIP/folder do not need that source again after setup.

The original manuals are installed in the Manuals folder and linked directly from the MechWarrior 3 Remastered Start-menu group.
