# MechWarrior 3 Remastered v1.0.0

Initial public installer release with MW3 extraction from a user-selected original ISO, the official v1.2 update, ZipperFixup, the project's DDrawCompat/remaster build, CD-music support, optional Pirate's Moon ISO installation, shortcuts, and an uninstaller.

The US MW3 path passed its complete automated smoke test. Pirate's Moon executable patching was tested, but a complete expansion ISO was unavailable for an end-to-end media test.
